<h2><a href="https://www.geeksforgeeks.org/problems/egg-dropping-puzzle-1587115620/1">Egg Dropping Puzzle</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given <strong>n </strong>identical eggs and you have access to a<strong> k</strong>-floored building from&nbsp;1 to k.</span></p>
<p><span style="font-size: 14pt;">There exists a floor f where 0 &lt;= f &lt;= k such that any egg dropped from a floor higher than f&nbsp;will break, and any egg dropped from or below floor f&nbsp;will not break. <br>There are few rules given below.&nbsp;</span></p>
<ul>
<li><span style="font-size: 14pt;">An egg that survives a fall can be used again.</span></li>
<li><span style="font-size: 14pt;">A broken egg must be discarded.</span></li>
<li><span style="font-size: 14pt;">The effect of a fall is the same for all eggs.</span></li>
<li><span style="font-size: 14pt;">If the egg doesn't break at a certain floor, it will not break at any floor below.</span></li>
<li><span style="font-size: 14pt;">If the egg breaks on a certain floor, it will break on any floor above.</span></li>
</ul>
<p><span style="font-size: 14pt;">Return the minimum number of moves&nbsp;<span style="box-sizing: border-box; margin: 0px; padding: 0px;">you need to determine the value of&nbsp;<strong>f</strong> with certainty</span>.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>

Following is the strategy to do so:<br></span><span style="font-size: 14pt;">Drop from floor 8 → If breaks, check 1-7 sequentially.<br></span><span style="font-size: 14pt;">Drop from floor 15 → If breaks, check 9-14.<br></span><span style="font-size: 14pt;">Drop from floor 21  → If breaks, check 16-20.<br></span><span style="font-size: 14pt;">Drop from floor 26 → If breaks, check 22-25.<br></span><span style="font-size: 14pt;">Drop from floor 30 → If breaks, check 27-29.<br></span><span style="font-size: 14pt;">Drop from floor 33 → If breaks, check 31-32.<br></span><span style="font-size: 14pt;">Drop from floor 35 → If breaks, check 34.<br></span><span style="font-size: 14pt;">Drop from floor 36 → Final check.</span></pre>
